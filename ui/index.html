Вставьте ключ, вставьте код, нажмите «Запустить». Остальное приложение сделает само.

Ключ показывается один раз при создании приложения в кабинете .

Достаточно одного файла. В коде должна быть переменная app = FastAPI(). Библиотеки из import программа скачает сама.

Настройки

Нужна, если в коде используются ваши файлы (шаблоны, базы, картинки) или свои модули. Код запустится из этой папки.

Обычно не нужен: программа выберет свободный порт сама. Заполните, если сервер должен быть доступен локально по одному и тому же адресу.
